# Chit brand assets

The Blind Seam mark is a single paper chit divided by an unreadable middle. Both public endpoints
remain visible; their private attribution cannot be followed across the seam.

- `logo.svg` — canonical vector mark
- `logo.png` — 512px raster export
- `favicon.svg` — scalable browser icon
- `favicon.ico` — 16/32/48px browser icon set
- `favicon-{16,32,48}.png` — source rasters packed into the ICO
- `BRAND-TRUTH.md` — locked product meaning and palette
- `ART-DIRECTION.md` — visual rules for product UI
- `candidates/` — Gate 1 exploration and review record
